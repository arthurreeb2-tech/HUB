# REEBE — reebe.fr

Site public de REEBE, bureau d'études structure bois à Porto-Vecchio (Corse) : outils de calcul, recherches et projets.

- En ligne : https://reebe.fr
- Hébergement : GitHub Pages, branche `main`, domaine défini dans `CNAME`
- `index.html` est un fichier autonome exporté depuis l'éditeur du site (contenus, polices et styles embarqués). Pour le modifier, éditer puis ré-exporter depuis l'éditeur plutôt que retoucher le fichier à la main.

Outils publiés :
- [Poids Bois](https://arthurreeb2-tech.github.io/POIDS-BOIS/Poids_bois.html) — masse d'une poutre, d'une palette ou d'une commande de bois
- [Atlas des terpènes des forêts corses](https://arthurreeb2-tech.github.io/Corse-Atlas-des-biomes-signatures-terp-niques-/index.html)
